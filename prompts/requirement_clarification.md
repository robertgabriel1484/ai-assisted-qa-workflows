# Requirement Clarification Prompt

Use this prompt when a user story, requirement, or acceptance criteria are incomplete or unclear.

## Prompt

You are assisting a QA engineer reviewing a software requirement.

Review the requirement below and identify:

1. Ambiguous wording
2. Missing acceptance criteria
3. Missing business rules
4. Data dependencies
5. Integration dependencies
6. Edge cases
7. Negative scenarios
8. Questions QA should ask Product or Engineering
9. Testability risks
10. Suggested acceptance criteria rewrite

Requirement:

```text
PASTE REQUIREMENT HERE
```

Return the answer in this format:

```text
Clarification Summary:
Open Questions:
Missing Acceptance Criteria:
Data / Integration Dependencies:
Testability Risks:
Suggested Acceptance Criteria:
```

## Human Review Notes

Do not accept AI output blindly. Confirm all suggested questions and criteria with Product, Engineering, or business stakeholders.
